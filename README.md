# Double Ear 聲音實驗室

06 已改為六張手牌混音：四張隨機候選卡、長條手牌、獨立參數與 EQ，以及側邊「經典調配」基底收藏。點擊選卡、上下短拖調音量、向下拖超過 110px 或按 × 移除。保存的基底可載入 07 的四個槽位。

06 素材庫另有八張即時生成聲卡：賽博工業失真、故障微粒、VHS 低保真、地層共振、次原子振盪、四種蛙鳴、五種蘑菇訊號與四組編鐘。抽卡區每次隨機四張；完整搜尋區可依名稱、類型、描述、關鍵字與分類找到效果。特殊卡提供變體、強度、動態及隨機參數。

07 演奏台支援槽位開關／音量／長按更換、雙八度可縮放鍵盤，以及最長 90 秒的 JSON 操作錄製。錄製含初始基底快照與每個動作的毫秒時間，可在同頁儲存、重播、循環及匯出 JSON。操作以瀏覽器音訊時鐘重播，非取樣級自動化；不產生錄音檔。新資料分別保存在 `double-ear.cards.v1`、`double-ear.takes.v1`，既有收藏維持原 key。

07 已擴充為手機演奏工作台：C2–C7 八度導覽、琴鍵縮放與橫移、Pitch／Mod／Sustain、觸控 Slide／Vibrato、調式鎖定、三／七和弦、三套和弦進行與自動琶音。另有四 bank 共 16 音的鼓墊、808／Lo-Fi／Pop 鼓組、六種 Built-in FX，以及三組自訂 CC 和 XY 自動化板；聲音與控制動作皆可寫入 90 秒 JSON 時間軸。

混音室新增四種可疊加的薩滿聲景素材：框鼓、種籽沙鈴、泛音吟唱與儀式金屬鈴。它們可逐層開關與調整音量，節奏型素材跟隨主 BPM；「薩滿聲景」場景可一次載入四層，並支援 EQ、頻譜、收藏與循環播放。

## Vercel 部署

本專案可作為靜態網站部署至 Vercel。Radio 使用預先產生並提交的 `assets/radio-index.json`，正式網站不依賴本機 `server.js` 或後端資料庫。`vercel.json` 已固定 Framework Preset 為 `Other`、跳過 Build Command，並直接發布 repository 根目錄；GitHub 匯入後不需另設建置參數，之後每次推送會自動部署。

原始 `Old_Radio_Adverts_01.zip` 超過 GitHub 100 MiB 單檔限制並且不是網站執行所需，已由 `.gitignore` 與 `.vercelignore` 排除。部署版等距保留 102 段 MP3，素材數量較前一版減少約 70%，大小由 80.57 MiB 降至 23.35 MiB；原始 ZIP 仍留在本機，可用來恢復未部署素材。若 radio 檔案有增減，執行 `npm run build` 後提交更新的索引。

收藏、感想與播放清單使用瀏覽器 `localStorage`，不需伺服器。資料綁定網站 origin：相同正式網域會保留；換瀏覽器、清除網站資料或使用不同 Vercel Preview 網址時不會自動同步。可用頁面上的「匯出設定」下載 JSON 備份。

「多基頻疊加」位於混音室主頻率滑桿下方。展開後可新增最多三個附加基頻（總共四層）、輸入自訂頻率或套用三／四層預設。主基頻仍由上方滑桿控制；全部共用差頻、波形、擺盪及空間設定，相同頻率自動合併。疊加參數會隨收藏保存及還原。

混音室同頁提供即時輸出頻譜與五段參數 EQ（20 Hz–20 kHz、±12 dB）。拖曳圓點調頻率與增益、滾輪調 Q，也可用鍵盤或數值欄調整；EQ 可旁通及歸零。

「留下這次聆聽」儲存目前聲層、radio 選曲、EQ、總音量、名稱、感想及播放時長。收藏清單支援上一首／下一首、暫停／繼續與單曲／全部循環，播放時重新合成音訊。資料保存在目前瀏覽器、相同網址與連接埠的 localStorage；不保存音檔。可匯出 JSON 設定備份，清除瀏覽器資料會移除本機收藏。載入編輯後再儲存會建立一份新收藏。

混音室 `#/mixer` 已加入六種可同時疊加的太空／復古合成音，以及 `assets/radio` 內的 102 段廣播。素材庫由靜態 `assets/radio-index.json` 提供；本機請使用 `npm start` 啟動（預設連接埠 4993）。

06 手牌點擊選中，旁邊 ON/OFF 控制開關；上下短拖、滑鼠滾輪或上下方向鍵調音量，向下長拖或 Delete 移除。載波頻率、差頻與 BPM 各有獨立連續滑桿及推薦值快捷鍵，進階音色、空間與錯拍設定可展開「聲音細節」。Radio 可搜尋選曲並循環播放，調整其他聲層不會重播 radio。

以 Web Audio API 製作的瀏覽器雙耳聲音與生成式琶音實驗台。包含七個由淺入深的實驗與演奏頁面，不需要 EEG 或後端服務。

## 啟動

```powershell
npm start
```

依終端機顯示的網址開啟頁面。請使用耳機並從低音量開始。

## 測試

```powershell
npm test
```

測試不會播放聲音。目前涵蓋差頻計算、節拍間隔、聲像及可重現亂數。

## 實驗頁面

- 純粹差頻
- 頻譜包覆
- 電子植物園（八種生成式琶音）
- 左右軌道
- 雙耳錯拍
- 完整混音室

網址使用 hash 路由，例如 `#/garden` 與 `#/mixer`，可直接收藏或分享指定實驗頁。
